# InvoiceGenie Development Rules

This directory contains the development standards and guidelines for the InvoiceGenie project.

## 📁 Rules Structure

### Core Development Standards
- **[development-standards.md](./development-standards.md)** - Main development standards, coding practices, UI/UX guidelines, testing standards, and security practices

### AI Integration Strategy
- **[ai-strategy.md](./ai-strategy.md)** - Comprehensive AI integration strategy with specific features, implementation roadmap, and technical specifications

## 🎯 How to Use These Rules

1. **For Development**: Follow the standards in `development-standards.md` for consistent code quality
2. **For AI Features**: Reference `ai-strategy.md` when implementing AI capabilities
3. **For Code Reviews**: Use the checklists provided in the development standards
4. **For New Features**: Ensure new features align with both development standards and AI strategy

## 🔄 Updating Rules

- Update rules as the project evolves
- Add new rule files for specific domains (e.g., `api-standards.md`, `ui-components.md`)
- Keep rules concise and actionable
- Include code examples for clarity

---

*These rules ensure consistent, high-quality development practices across the InvoiceGenie project.*
